공개 주소: https://gorbachev8086.github.io/ek-training/

- [제품 가이드](https://gorbachev8086.github.io/ek-training/): 제품 기능과 사용법, 공개 슬라이드 158개
- [실습 위주 예제](https://gorbachev8086.github.io/ek-training/examples/): 실습 교재 50쪽과 활용 사례 교재 14쪽

모듈별 목차, 전체 텍스트·표 검색, 슬라이드 확대, 이전·다음 이동, 모바일 읽기와 원본 쪽 번호 링크를 제공합니다. 예: `#slide-72`.

## 자료 범위

각 자료의 본문과 페이지 순서는 독립적으로 유지합니다. 실습 교재와 활용 사례 교재의 문장·표·이미지·사례를 다른 파일이나 교재의 참고·인용·내용 병합에 사용하지 않습니다. 두 자료 자체의 웹 변환·열람·공개 범위에서만 사용합니다.

제품 가이드는 원본 164장 중 숨김 6장을 제외한 158장을 제공합니다. 공개 화면 일부는 계정·연결 정보가 가려져 있습니다. PDF 5편은 제공된 원문과 파일명을 유지하며, 다운로드 목록에 저자·출처·라이선스를 표시합니다.

## 게시와 미리보기

GitHub 저장소의 Settings → Pages → Deploy from a branch → main → /(root)를 사용합니다. 이 폴더의 공개 사이트 파일 전체와 `.nojekyll`을 함께 게시합니다.

Python이 설치된 PC에서는 이 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000/`을 엽니다. JSON을 읽는 페이지이므로 HTML 파일만 더블클릭하는 방식은 지원하지 않습니다.

원본 PPT, 발표자 노트, 내부 경로, 비밀값, 원시 이미지 및 작업·검토 파일은 공개 패키지에 포함하지 않습니다. 웹 열람 검증은 실제 EK 환경에서의 연결·실행 검증과 구분합니다. 자료와 이미지의 출처 및 저작권은 해당 권리자에게 있습니다.
